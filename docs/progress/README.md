# Pamięć projektu Kandex

Ten katalog jest trwałą pamięcią procesu tworzenia Kandex. Ma umożliwiać wznowienie pracy w nowym czacie bez odtwarzania całej historii rozmów.

## Zasady

Po każdej większej zmianie aktualizuj odpowiedni plik:
- CURRENT_STATE.md — aktualny stan projektu.
- CHANGELOG.md — chronologiczna historia zmian.
- DECISIONS.md — ważne decyzje techniczne i ich uzasadnienie.
- ISSUES.md — znane problemy i rzeczy do sprawdzenia.
- NEXT_STEPS.md — plan dalszych prac.
- SESSION.md — ostatnia sesja i punkt wznowienia.

Przed większą pracą przeczytaj README.md, CURRENT_STATE.md, SESSION.md i NEXT_STEPS.md.

Nie zapisuj tutaj haseł, tokenów, danych logowania ani innych sekretów.
